# 工作3: URL过滤设置方案设计

## 功能目标
在uNetwork.html页面下载接口数据时，能够过滤一些url的数据，让这些数据下载到json数据中。

## 设计方案

### 1. 过滤配置界面设计
在uNetwork页面增加一个"过滤设置"面板，包含以下功能：

**界面位置**: 在现有的操作栏（录制、清空、导出按钮区域）下方增加一个可展开/收起的设置面板

**设置项**:
- **过滤模式选择**:
  - `包含模式` (白名单): 只导出匹配规则的URL数据
  - `排除模式` (黑名单): 导出所有数据，但排除匹配规则的URL
  
- **过滤规则配置**:
  - 支持多条规则，每条规则包含：
    - URL匹配模式（支持正则表达式或简单字符串匹配）
    - 规则描述（可选，用于用户备注）
    - 启用/禁用开关

### 2. 过滤规则数据结构
```javascript
const filterConfig = {
  mode: 'include', // 'include' 或 'exclude'
  rules: [
    {
      id: '1',
      pattern: '/api/users.*',
      description: '用户相关接口',
      enabled: true,
      type: 'regex'
    },
    {
      id: '2', 
      pattern: 'localhost:4001/api/products',
      description: '产品接口',
      enabled: true,
      type: 'string'
    }
  ]
}
```

### 3. 具体功能
- **快速过滤按钮**: 在每个请求行增加"添加到过滤器"按钮
- **批量设置**: 提供常用过滤模板
- **实时预览**: 显示当前过滤规则将影响多少条请求
- **持久化存储**: 过滤配置保存到Chrome扩展本地存储

### 4. 导出功能增强
修改现有的exportRequests函数，增加过滤逻辑，导出时应用过滤规则。

### 5. 用户界面交互流程
1. 设置过滤规则 → 2. 预览过滤效果 → 3. 执行导出
